# Baby - 2D Platform Game

Basit ama eğlenceli bir 2D platform oyunu.

## Özellikler

- 🎮 Oyuncu karakteri kontrolü (sol/sağ hareket, atlama)
- ⬇️ Yerçekimi ve fizik sistemi
- 🟩 Platformlar
- 👹 Düşmanlar
- 🎯 Zorlayıcı seviyeler

## Gereksinimler

- Python 3.8+
- Pygame

## Kurulum

```bash
pip install -r requirements.txt
```

## Oyunu Çalıştırma

```bash
python main.py
```

## Kontroller

- **A / Sol Ok**: Sola hareket
- **D / Sağ Ok**: Sağa hareket
- **SPACE / W / Yukarı Ok**: Atlama
- **ESC**: Çıkış

## Oyun Mekanikler

- Mavi karakteri kontrol et
- Platformlara zıpla
- Kırmızı düşmanları ezilerek öldür (üzerinden zıpla)
- Düşmanlardan kaç veya öldür
- Ekranın altına düşme - oyun sona eriyor!
